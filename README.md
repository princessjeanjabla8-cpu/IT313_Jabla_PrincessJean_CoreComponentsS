
# IT313 Student Directory Viewer

## Problem Description

The Student Directory Viewer is a React Native application
for academic advisers. It displays student photos, names,
and year levels. Advisers can search students and flag them
for academic advising.

## Component Structure

### StudentDirectory
Manages the student list, search query, and flag states.
It filters students and displays the cards in a ScrollView.

### StudentCard
Displays the student's photo, name, year level, and
Flag for Advising button.

## Core Components

- View: Organizes the screen layout.
- Text: Displays text.
- Image: Displays student photos.
- ScrollView: Displays a scrollable student list.
- TextInput: Accepts search input.
- Pressable: Handles button interaction.

## How to Run

1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npx expo start`.
4. Open the app using Expo Go or an emulator.
